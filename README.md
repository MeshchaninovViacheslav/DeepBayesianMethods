# Deep Bayesian Methods

Welcome to the course! This course is a continuation of §Bayesian Methods in Machine Learning. In this part, we will focus on applications of Bayesian methods to modern neural networks.

A significant portion of the course will be devoted to generative models (see the class schedule below).
